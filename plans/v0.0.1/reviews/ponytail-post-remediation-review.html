MEDIUM · future-plugin correctness

Validate registry catalogue/factory parity

LOW · cold-scan efficiency

Single-flight package-doc snapshots

Parallel workers may each miss the package-doc map and build the same directory snapshot. It is race-safe, but it duplicates I/O. Package type facts already use a per-directory sync.Once pattern.

Smallest change: reuse that entry-plus-once pattern for package docs and prove one build under concurrency.
