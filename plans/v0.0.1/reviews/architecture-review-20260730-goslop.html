Strong · in-process

Problem. Detector state and lifecycle leak across the scan seam; a warm hit can bypass required project-state accumulation.

Solution. One ScanSession interface runs a resolved scan; its implementation owns detector instances, lifecycle, project facts, and finalization.

  • Locality: scan state concentrates
  • Leverage: one cache contract
  • Tests cross one interface
