# goslop product site

React + Vite + Tailwind + shadcn/ui marketing site for **goslop**.

## Scripts

```sh
npm install
npm run dev      # local preview
npm run build    # production build → ../docs (repo root)
npm run preview  # preview the production build
```

`npm run build` writes static assets into the repository root `docs/` folder so GitHub Pages (or any static host) can serve them from `/docs`.
